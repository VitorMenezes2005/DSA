# DSA Journey (Java)

Repositório dedicado aos meus estudos de **Data Structures & Algorithms (DSA)** utilizando **Java**. O objetivo é desenvolver uma base sólida em estruturas de dados, análise de complexidade e resolução de problemas, com foco em preparação para entrevistas técnicas e evolução como desenvolvedor.

## Objetivos

* Fortalecer fundamentos de algoritmos e estruturas de dados
* Praticar resolução de problemas de forma consistente
* Melhorar raciocínio lógico e capacidade de otimização
* Registrar minha evolução ao longo do tempo
* Criar um histórico público de estudos e commits

## Tecnologias

## Progresso

Este repositório é atualizado conforme avanço nos estudos. A ideia é manter uma rotina consistente de prática e utilizar os commits como um registro da minha evolução.

## Filosofia

Mais importante do que resolver rapidamente é **entender profundamente** cada problema. Sempre que possível, busco:

* escrever código limpo;
* analisar a complexidade de tempo e espaço;
* comparar diferentes abordagens;
* revisar soluções anteriores.
